# 💰 Expense Tracker

A responsive expense tracking web application built with HTML, CSS, and vanilla JavaScript.

## 🚀 Live Demo

Coming soon.

## 📌 About the Project

Expense Tracker allows users to record and manage their daily expenses directly in the browser.

Users can add, edit, delete, search, filter, and sort expenses. Expense data is stored in the browser using Local Storage, so the data remains available after refreshing the page.

## ✨ Features

- Add expenses
- Edit existing expenses
- Delete expenses
- Search expenses by description
- Filter expenses by category
- Sort expenses by:
  - Newest
  - Oldest
  - Highest amount
  - Lowest amount
- Calculate total expenses
- Display number of expenses
- Form validation
- Persistent data using Local Storage
- Responsive design for mobile devices

## 🛠️ Technologies Used
